# Şanlıurfa Korsan Taksi

Şanlıurfa korsan taksi hattında GAP Havalimanı şehrin kuzeydoğusunda kalır. Merkez ilçelerden Karaköprü 32, Haliliye 38, Eyyübiye 40 kilometre uzaklıktadır. Batıdaki Birecik ve Halfeti için Gaziantep, doğudaki Viranşehir ve Ceylanpınar için Mardin Havalimanı daha yakındır.

Göbeklitepe sabah serinliğinde, Balıklıgöl ve çarşı akşamüstü gezilir. Harran'daki kümbet evlere 85 kilometre yol gidilir. Halfeti'de tekne turuna çıkacak olan iskelede bırakılır ve tur bitince alınır.
